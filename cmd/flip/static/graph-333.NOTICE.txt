M3 over F2 recorded-walk data attribution

The schemes and transitions in graph-333.json were produced by running a
locally instrumented copy of the flip-graph search program from:

  Flip Graphs for Matrix Multiplication
  Manuel Kauers and Jakob Moosbauer
  https://github.com/jakobmoosbauer/flips
  revision e31a0a0f0d2577cee5da047ca7dcae0c61992e40
  paper: https://arxiv.org/abs/2212.01175

The walk starts from that repository's `333-27-mod2.exp` schoolbook scheme.
The instrumentation patch is recorded in `cmd/flip/generate/333walk-trace.patch`
and is distributed, like the program it modifies, under the GNU General Public
License, version 3 or later; the license text is reproduced in
graph-222.LICENSE.txt. The exported `.exp` dataset is archived in
`cmd/flip/generate/333walk-27-to-23.tar.gz`.

The graph JSON itself was generated by this project's importer from that
dataset. The recorded walk, milestone neighborhood sampling, deterministic
layout, and highlighted path are additions in this project; no program source
or figure geometry from the paper is copied into the JSON.
